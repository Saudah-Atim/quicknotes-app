# QuickNotes

QuickNotes is a simple note-taking web application that allows users to add, organize, search, and delete notes. Users can choose a category for each note, and the notes are saved in the browser so they remain available after refreshing the page.

## Features

- Add new notes
- Choose a category: Personal, Work, or Study
- Search notes
- Delete notes
- Validate notes before adding them
- Limit notes to 200 characters
- Display the number of notes
- Save notes using localStorage
- Keep notes after refreshing the page
- Responsive design for smaller screens

## How to Run in a Browser

1. Download or clone the QuickNotes project.
2. Open the `quicknotes-app` folder.
3. Double-click `index.html`.
4. The QuickNotes application will open in your web browser.
